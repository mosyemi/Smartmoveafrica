# SmartMoveAfrica Roadmap

## Phase 1: Planning
- Finalize requirements and architecture docs.
- Freeze MVP scope and success metrics.

## Phase 2: MVP
- Complete auth session provider and repository.
- Upgrade traffic reporting persistence and map rendering.
- Add computed dashboard metrics.

## Phase 3: Transport
- Matatu tracking list and route status.
- Fare estimation with configurable rules.
- Notification feed for transport incidents.

## Phase 4: Air
- Flight schedule and airport monitor screens.
- Airspace status indicators and filters.

## Phase 5: AI
- Traffic trend predictions.
- Route recommendation cards and insights.

## Phase 6: Mobile Hardening
- Permission handling and location updates.
- Notification service wiring and UX polish.

## Phase 7: Quality
- Add unit/widget/integration tests.
- Security and performance checks.

## Phase 8: Deployment
- Release checklist and versioning guide.
- Build APK/AAB and rollout readiness steps.
